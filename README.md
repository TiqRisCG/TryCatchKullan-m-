# Nesne Yönelimli Programlama (OOP) Projesi

## 📘 Proje Hakkında

Bu proje, **Nesne Yönelimli Programlama (OOP)** ilkelerini kullanarak hazırlanmıştır. Amaç, sınıflar, nesneler, kalıtım, çok biçimlilik ve kapsülleme kavramlarını örneklerle göstermektir.

## 🚀 Özellikler

* Sınıf ve nesne yapılarının uygulanması
* Miras (Inheritance) kullanımı
* Çok biçimlilik (Polymorphism) örnekleri
* Kapsülleme (Encapsulation) ve soyutlama (Abstraction)
* Java dilinde OOP mantığının örneklenmesi

## 🧩 Kullanılan Teknolojiler

* **Programlama Dili:** Java
* **IDE:** IntelliJ IDEA / Eclipse / VS Code
* **Java Sürümü:** 8 veya üzeri

## ⚙️ Kurulum ve Çalıştırma

1. Depoyu klonlayın:

   ```bash
   git clone https://github.com/<kullanici-adiniz>/NesneYönelimliProgramlama.git
   cd NesneYönelimliProgramlama
   ```
2. Projeyi IDE üzerinden açın veya terminalden derleyin:

   ```bash
   javac Main.java
   java Main
   ```

## 🧠 OOP İlkeleri

* **Kapsülleme:** Verileri gizleyip sadece gerekli metotlarla erişim sağlanır.
* **Kalıtım:** Alt sınıflar, üst sınıfların özelliklerini devralır.
* **Polimorfizm:** Aynı isimli metotlar farklı davranışlar gösterebilir.
* **Soyutlama:** Gereksiz detaylar gizlenir, sadece temel işlevler gösterilir.
